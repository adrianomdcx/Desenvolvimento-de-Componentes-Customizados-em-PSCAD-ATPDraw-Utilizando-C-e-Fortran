# Desenvolvimento-de-Componentes-Customizados-em-PSCAD-ATPDraw-Utilizando-C-e-Fortran
Este repositório reúne implementações em C e Fortran voltadas à customização de elementos elétricos e de sinais nos ambientes PSCAD e ATPDraw. Para o PSCAD, os modelos são escritos em C e posteriormente compilados em Fortran, portanto, deve-se obrigatoriamente do compilador C-> Fortran.
